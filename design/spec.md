# Darkroom / The moving image archive

User direction: an ambitious original redesign, with creative execution delegated to the agent.

Keep the photographic identity, but turn it into a complete editorial film archive: warm paper, near-black ink, vermilion safelight, oversized tightly set condensed typography, precise monospaced annotations. No promotional claims inside the video.

Showcase: slim archive masthead; monumental DARKROOM wordmark; asymmetric introduction; framed screening room with archive metadata; footage and size selection; contact-print film selection; concise design notes and keyboard reference. A lights-out toggle dims the surrounding page without affecting player contrast. Source control and workbench links remain available.

Skin: retain Video.js controls, hotkeys, announcer, captions, error dialog and menus. Control source order remains unchanged. Square tactile keys and opaque control surfaces. Main play key uses vermilion with dark text. Central initial play button is a cream circular exposure key. Menus use the same cream/ink/red system.

Signature: the seek slider contains a real contact strip sampled from the current Mux video. Unwatched frames are dim monochrome; watched frames develop into color as playback advances. The ordinary accessible Video.js seek slider remains the interaction surface. Hover preview appears as a photographic slide mount. Native/non-Mux media retains a functional standard timeline.

Motion: precise press feedback, film advance tied to playback, brief menu transitions. Page lights fade through a single transition token. No decorative perpetual animation outside playback. Reduced motion disables film advance and transitions. Focus and contrast remain visible in lights-out mode.

Responsive: container queries simplify controls while preserving play, seek, time, mute, settings and fullscreen; at least 44px primary targets. Page becomes a single column on phones; no horizontal scrolling. Keyboard and source order agree.

Derived execution: warm white #eee9df, ink #171714, vermilion #ff603b; licensed existing IBM Plex families; 1px rules; 4px control corners; pill shape reserved for small status indicators. Real footage credits and Apache 2.0 licensing remain explicit.
